## 🔄 工序流转规则

### 建筑工程流转逻辑
```
C01 地基与基础 → C02 主体结构 → C04 屋面 → C05 给排水 → C06 电气 → C03 装饰装修
```

**关键节点**:
1. **主体结构验收** - 必须完成后才能进入装修阶段
2. **屋面防水验收** - 必须完成淋水/蓄水试验
3. **隐蔽工程验收** - 钢筋工程、防水工程、电气管线必须先验收再隐蔽

### 装修工程流转逻辑
```
D01 抹灰 → D04 隔墙 → D03 吊顶 → D11 地面 → D02 门窗 → D08 涂饰 → D10 细部
```

**关键节点**:
1. **抹灰工程** - 必须先完成, 养护期 ≥ 7天
2. **防水工程** - 厨卫地面必须先做防水再贴砖
3. **吊顶工程** - 必须在墙面涂饰前完成
4. **木地板铺装** - 必须在涂饰、安装工程全部完成后进行
