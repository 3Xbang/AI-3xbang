# 表单字段使用指南 - "拍照为主，文字为辅"

## 设计原则

✅ **必填项**：照片（至少3张）  
⚠️ **可选项**：文字说明（简短即可，不超过100字）  
❌ **不需要**：冗长的报告、复杂的数据填写

## 五、字段说明汇总

### node_records 表（节点打卡）

| 字段名 | 类型 | 必填 | 说明 | 推荐长度 |
|-------|------|------|------|---------|
| **photos_json** | JSONB | ✅ | 至少3张照片的URL数组 | 3-10张 |
| **photo_count** | INTEGER | ✅ | 照片数量（自动计算） | >= 3 |
| **watermark_info** | JSONB | ✅ | 水印信息（自动生成） | - |
| **work_description** | TEXT | ⚠️ | 工作说明（简短描述） | 0-100字 |
| **notes** | TEXT | ❌ | 备注（极少使用） | 0-200字 |

### material_records 表（材料进场）

| 字段名 | 类型 | 必填 | 说明 | 推荐长度 |
|-------|------|------|------|---------|
| **material_name** | VARCHAR | ✅ | 材料名称 | - |
| **quantity** | DECIMAL | ✅ | 实收数量 | - |
| **unit** | VARCHAR | ✅ | 单位 | - |
| **photos_json** | JSONB | ✅ | 至少3张照片 | 3-10张 |
| **planned_quantity** | DECIMAL | ⚠️ | 计划数量（用于对比） | - |
| **supplier_name** | VARCHAR | ⚠️ | 供应商名称 | 0-200字 |
| **delivery_person** | VARCHAR | ⚠️ | 送货人 | 0-100字 |
| **quality_notes** | TEXT | ⚠️ | 质量说明 | 0-150字 |
| **notes** | TEXT | ❌ | 其他备注 | 0-200字 |

### issue_reports 表（异常上报）

| 字段名 | 类型 | 必填 | 说明 | 推荐长度 |
|-------|------|------|------|---------|
| **issue_title** | VARCHAR | ✅ | 异常标题 | 10-200字 |
| **issue_description** | TEXT | ✅ | 详细说明 | 20-200字 |
| **photos_json** | JSONB | ⚠️ | 现场照片（建议拍） | 0-10张 |
| **voice_text** | TEXT | ❌ | 语音转文字 | 0-500字 |

## 六、使用场景示例

### 场景1：现场工人完成水电安装
```
张三完成主卧水电安装后：

1. 点击【节点打卡】
2. 选择"水电布管"节点
3. 拍摄3张照片：
   - 全景照：整个房间的管线布局
   - 细节照1：开关插座底盒位置
   - 细节照2：强弱电分离情况
4. (可选) 填写工作说明："主卧水电管线安装完成"
5. 点击【提交】

✅ 30秒完成！无需填写复杂表格。
```

### 场景2：材料车到了
```
李四收到水泥送货后：

1. 点击【材料进场】
2. 选择"水泥"，输入"50吨"
3. 拍摄3张照片：
   - 送货单照片
   - 水泥袋特写（看生产日期）
   - 堆放全景
4. (可选) 填写质量说明："水泥袋完好，生产日期2024-01"
5. (可选) 填写供应商："苏梅建材公司"
6. 点击【提交】

✅ 1分钟完成！系统自动计算偏差。
```

### 场景3：遇到突发问题
```
张三发现钢筋不够了：

1. 点击【异常上报】
2. 填写标题："钢筋数量不足"
3. 填写说明："今天需要12mm钢筋300kg，但仓库只剩150kg，急需补货"
4. 拍摄现场照片（仓库剩余钢筋）
5. 点击【提交】

✅ 老板立即收到通知，马上回复处理。
```

## 八、核心原则总结

### ✅ 要做的
1. **照片是核心凭证** - 必须至少3张，带水印
2. **文字是辅助说明** - 可选，简短即可（50-150字）
3. **操作要极简** - 拍照 + 可选文字 + 提交，3步完成

### ❌ 不做的
1. **不强制填写长篇报告** - 现场工人文化水平有限
2. **不设置复杂的下拉选项** - 保持表单简洁
3. **不要求填写太多字段** - 核心字段3-5个即可

### 🎯 平衡点
- **必填**：照片（至少3张）+ 节点/材料名称 + 数量（材料用）
- **推荐填写**：工作说明（50-100字）、质量说明（50-150字）
- **可选**：供应商、送货人、其他备注

---

**设计哲学**：  
**"照片是证据，文字是补充。能用图说清楚的，绝不强制写字。"**
